# AternixMU – testovací launcher pro Season 6

[Stáhnout ZIP](https://github.com/netronek/MU-ONLIE/raw/refs/heads/launcher-test-20261104/downloads/AternixMU_Launcher_S6_test.zip)

Zavřete hru, zazálohujte původní launcher a balíček rozbalte přímo vedle klientského `main.exe` a `main.premium`. Spusťte `MuLauncher.exe`. Balíček neobsahuje herní klient.

Nastavení: AternixMU, Season 6 / Update 42; ConnectServer `141.95.47.104:44405`, server code `0`; web `https://www.aternixmu.eu/`. Tlačítko účtu je skryté. Aktualizační zdroj je prázdný, takže se nestahují cizí aktualizace. CZ/EN mění jen jazyk launcheru, bez přepisování herních překladů.

Byla ověřena struktura PE/.NET, metoda spuštění a konfigurace statickou analýzou. Spuštění GUI na Windows, připojení a spuštění hry ještě nebyly ověřeny. Jde o testovací verzi, nikoli hotovou distribuci pro hráče. Podrobnosti a postup návratu jsou v `CTI-ME.txt` uvnitř ZIPu.
